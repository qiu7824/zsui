# ZSUI v0.2.0

## 中文

ZSUI v0.2.0 是第一个完成三桌面平台闭环的正式版本。同一份 Rust
`State / Msg / view / update` 应用代码可进入 Win32、AppKit、Linux Direct 或
GTK4 宿主；应用层不包含平台枚举、条件编译、原始窗口句柄或平台事件循环。

### 正式范围

- 49 个组件家族均具备可运行表面，并通过独立 Cargo feature 按需编译；默认构建
  只包含 `window + button + label`。
- 共享布局完成文字实测、宽度相关换行、递归固有高度、裁剪与滚动闭环，平台字体、
  DPI 或缩放变化会使保留测量失效，不会复用错误缓存。
- Windows 使用系统消息字体和 ClearType；AppKit 使用系统字体与 Core Text；Linux
  默认使用 Fontconfig/Pango/Cairo，也可选择不链接 Cairo/Pango 的纯 Rust 文字与
  tiny-skia 配置。
- 文本输入、焦点、选择、撤销、视觉顺序双向导航、IME preedit/commit/cancel、
  候选位置几何和滚动由同一成形几何驱动。
- 原生菜单、快捷键、UTF-8/RGBA 剪贴板、系统消息对话框、打开/保存面板、托盘、
  热键、主题、语义图标与辅助功能均保持安全公共 API 和平台后端隔离。
- Notepad 验收会从真实命令按钮打开 Win32 common dialog、AppKit sheet、XDG portal
  或 GTK4 `FileChooserNative`，验证父窗口关系、截图、原生取消和强类型状态回传。
- `UiDocument`、`zsui-uic` 与独立 `zsui-viewer` 支持稳定 ID、强类型绑定、结构验证、
  热重载、状态迁移和 release 嵌入；正式应用不需要携带 Viewer 或文件监听器。
- 固定 CI 在 Windows 2025、macOS 15 ARM64、Ubuntu 24.04 X11、真实 Weston Wayland
  上运行最终平台表面、输入、IME 协议、辅助功能、菜单、文件面板和内存证明。
- `zsui::stable` / `zsui::prelude` 提供受语义版本约束的应用开发门面；公开稳定
  Rustdoc 覆盖率实测 100%，CI 下限为 70%。
- Windows 11 与 Ubuntu 24.04 ARM64 使用原生 GitHub Runner 执行真实窗口、输入、
  IME、辅助功能与最终表面截图，不以交叉编译冒充运行证明。
- 发布流水线提供 Windows 安装器、macOS DMG、Linux DEB/便携包、SHA-256 更新清单、
  GitHub/Sigstore 构建证明，并预留 Authenticode、Developer ID 与 notarization 密钥槽。
- 四档性能矩阵把 Minimal、Common、Full Native App 与 Viewer 分开，并在同视觉
  复杂度下与 egui、Iced、Slint、Tauri 比较；Viewer 成本不会归入正式应用。

### 安装

```toml
[dependencies]
zsui = { version = "0.2.0", default-features = false, features = [
  "window", "button", "label"
] }
```

Release 附件同时包含 Windows 便携 EXE/安装器、macOS DMG 与 Linux DEB/便携包；
没有 WebView，Windows 用户界面程序也没有控制台窗口。安装、签名与更新协议见
`docs/distribution.md`。
真实中文输入法候选窗、VoiceOver/Narrator/Orca 的人工体验属于发布前人工检查，自动化
报告只声明可重复验证的 IME 协议、插入点几何和辅助功能桥接证据。

## English

ZSUI v0.2.0 is the first stable release to close the three-desktop-platform
loop. One Rust `State / Msg / view / update` application source enters Win32,
AppKit, Linux Direct, or GTK4 without application-side platform enums,
conditional compilation, raw window handles, or native event loops.

### Stable scope

- All 49 component families have runtime surfaces and remain independently
  selectable through Cargo features. Defaults contain only
  `window + button + label`.
- Shared layout uses measured text, width-dependent wrapping, recursive
  intrinsic height, clipping, and scroll containment. Platform font, DPI, or
  scale changes invalidate retained measurement data.
- Windows uses the system message font and ClearType, AppKit uses system fonts
  and Core Text, and Linux defaults to Fontconfig/Pango/Cairo with an optional
  pure-Rust text and tiny-skia profile that does not link Cairo/Pango.
- Text input, focus, selection, undo, visual-order bidi navigation, IME
  preedit/commit/cancel, candidate geometry, and scrolling share one shaped
  geometry source.
- Native menus, accelerators, UTF-8/RGBA clipboard data, system dialogs,
  open/save panels, status items, hotkeys, themes, semantic icons, and
  accessibility keep safe public contracts and backend isolation.
- The Notepad acceptance path opens Win32 common dialogs, AppKit sheets, XDG
  portals, or GTK4 `FileChooserNative` from real command buttons, then verifies
  ownership, captures, native cancellation, and typed state return.
- `UiDocument`, `zsui-uic`, and the separate `zsui-viewer` provide stable IDs,
  typed bindings, validation, hot reload, state migration, and release
  embedding. Formal applications do not ship Viewer watchers.
- Fixed CI runs final target surfaces, input, IME protocol, accessibility,
  menus, file panels, and memory proof on Windows 2025, macOS 15 ARM64,
  Ubuntu 24.04 X11, and a real Weston Wayland compositor.
- `zsui::stable` / `zsui::prelude` provide the semver-governed application
  surface. Visible stable Rustdoc coverage measures 100% with a 70% CI floor.
- Windows 11 and Ubuntu 24.04 ARM64 use native GitHub runners for real window,
  input, IME, accessibility and final-surface proof; cross-compilation is not
  accepted as runtime evidence.
- Release automation produces a Windows installer, macOS DMG, Linux DEB and
  portable packages, a SHA-256 update manifest, GitHub/Sigstore provenance,
  and optional Authenticode, Developer ID and notarization layers.
- The four-profile performance matrix separates Minimal, Common, Full Native
  App, and Viewer and compares equal visual workloads with egui, Iced, Slint,
  and Tauri. Viewer cost is never assigned to formal applications.

### Install

```toml
[dependencies]
zsui = { version = "0.2.0", default-features = false, features = [
  "window", "button", "label"
] }
```

Release assets include a portable Windows EXE and installer, macOS DMG, and
Linux DEB and portable package. They use no WebView, and the Windows GUI has no
console window. See `docs/distribution.md` for signing and update verification.
Real candidate-window experience and manual
VoiceOver/Narrator/Orca use remain human release checks; automation claims only
the repeatable IME protocol, caret geometry, and accessibility bridge evidence.
