# ZSUI v0.3.0-alpha.1

## 本阶段重点

0.3.0 的方向是 Native Proof CI：同一份应用源码在 Win32、AppKit 与 Linux
原生窗口运行，并由固定 Runner 生成最终平台表面、结构化报告和可审查回归证据。
本阶段推进 AppKit P0 的证据消费链，并把比较器从 ZSUI 运行时依赖中独立出来。

## 本阶段内容

- 版本线进入 `0.3.0-alpha.1`。
- 新增独立工具 `tools/native-proof`：
  - `compare`：递归发现 proof JSON/PNG，严格比较语义、窗口、Widget
    几何/焦点/消息/未处理命令与错误；
  - 对每个 Widget 关键区域和完整窗口做 RGBA 像素差异统计；
  - 输出洋红高亮 diff PNG 与 `summary.md`，任何场景失败返回非零退出码；
  - `init`：把一次已审查的 actual 证据提升为只读基线候选。
- 默认阈值沿用 0.3 策略：关键区域 `0.5%`、完整窗口 `1.0%`、通道容差 `32`。
- `tools/native-proof` 不进入 ZSUI 运行时依赖图，仅由 CI 和发布流程使用。

## 同时包含

- 自绘桌面应用外壳：`window-chrome` 自定义标题栏与拖动区域、最小化/最大化/关闭
  窗口命令；Canvas 悬停区域、带区域标记的指针事件、显式字号/颜色与图标字形；
  `AppCx::focus` 程序化焦点；菜单锚点、文本框提交与应用快捷键。
- Windows 默认 Rust 文字引擎：每个窗口共用一个文字引擎和已安装字体，View 测量
  不再反复初始化；中文 Semibold/Medium 回退保持在同一字体的粗体上。
- 构建修复：AppKit 原生截图启用 `objc2-app-kit` 的 Core Graphics 绑定；Linux
  无障碍树为右键菜单区域提供角色；DataViewer 对比工程锁文件跟随当前版本。
- 发布流程按标签读取对应的发布说明，带预发布后缀的版本标记为 Pre-release。

## 仍按计划后续推进

  `tests/native-baselines/macos-15-arm64` 基线。
- Win32 与 Linux Direct 迁移到同一 proof schema 后复用本比较器。
