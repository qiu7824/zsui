# ZSUI v0.2.0-preview.7

## 中文

本预览版扩展了 ZSUI 的统一 Rust 应用模型、可重载语义 UI 文档、平台原生体验规则和真实三平台验收。49 个组件家族均已有首轮运行面，并继续通过独立 Cargo feature 按需进入应用。

### 主要内容

- 一套 `State / Msg / view / update` 代码分别进入 Win32、AppKit 和 Linux 原生窗口，应用代码不包含平台枚举、条件编译或原始平台句柄。
- `UiDocument`、`zsui-uic` 和原生 `zsui-viewer` 支持结构验证、类型化绑定、稳定组件 ID、状态保留、滚动恢复和可视内容热重载；发布应用仍可将文档直接嵌入单进程二进制文件。
- Image、ItemsRepeater、SettingsCard、WorkbenchShell、MessageTimeline、Composer、InspectorPanel、Tooltip 和 Canvas 已进入可复用框架组件、文档运行时与组件目录。
- Tooltip 提供平台度量、延迟显示、键盘焦点触发、视口翻转与约束、自动关闭和无障碍描述；Canvas 提供保留式语义图元、裁剪、命中测试、指针捕获和无障碍 Canvas 角色。
- 自动组件 ID 由稳定 View 路径生成；显式 ID 仍可覆盖，用于跨重建状态、焦点和自动化定位。
- 文字测量、塑形、绘制、插入点、选择和 IME 候选位置共享同一几何来源；Windows 跟随系统消息字体与 ClearType，AppKit 使用系统字体/Core Text，Linux 使用平台配置字体与对应文字栈。
- Linux Direct 保留 Cairo/Pango 配置，并提供不链接 Cairo/Pango 的 `linux-direct-lite` 纯 Rust 配置；两者复用相同应用代码。
- 原生剪贴板支持 UTF-8 文本和校验后的 RGBA 图像。X11 所有权跨服务调用持续保留，写入、读取和原内容恢复均进入自动证明。
- Win32、AppKit、Wayland 和轻量 Linux 的真实窗口、输入、布局、最终平台截图、Viewer 场景和内存采样均由 GitHub Actions 自动执行。

### 安装

```toml
[dependencies]
zsui = { version = "0.2.0-preview.7", default-features = false, features = [
  "window", "button", "label"
] }
```

Windows 附件仅包含可直接双击运行的组件库 EXE，不需要 WebView 或控制台窗口。

本版本仍为预览版。父窗口绑定对话框与文件选择器的更完整交互证明、真实中文输入法候选窗、系统辅助技术、触摸/惯性滚动、Canvas 路径与多指针输入仍属于后续发布门槛。

## English

This preview expands ZSUI's unified Rust application model, reloadable semantic UI documents, platform-native experience rules, and real three-platform acceptance coverage. All 49 component families now have a first-pass runtime surface and remain independently selectable through Cargo features.

### Highlights

- One `State / Msg / view / update` program enters native Win32, AppKit, and Linux windows without platform enums, application-side conditional compilation, or raw platform handles.
- `UiDocument`, `zsui-uic`, and the native `zsui-viewer` provide structural validation, typed bindings, stable widget IDs, state retention, scroll restoration, and visual hot reload. Release applications can still embed documents directly into a single-process binary.
- Image, ItemsRepeater, SettingsCard, WorkbenchShell, MessageTimeline, Composer, InspectorPanel, Tooltip, and Canvas are reusable framework components represented in the document runtime and component catalog.
- Tooltip supplies platform metrics, delayed hover, immediate keyboard focus, viewport flipping and clamping, timed dismissal, and accessible descriptions. Canvas supplies retained semantic primitives, clipping, hit testing, pointer capture, and a Canvas accessibility role.
- Automatic widget IDs derive from stable View paths while explicit IDs remain available for cross-rebuild state, focus, and automation identity.
- Text measurement, shaping, painting, caret, selection, and IME candidate placement consume shared geometry. Windows follows the system message font and ClearType, AppKit uses system fonts/Core Text, and Linux uses its configured platform font and text stack.
- Linux Direct retains the Cairo/Pango profile and adds `linux-direct-lite`, a pure-Rust profile that does not link Cairo/Pango. Both reuse identical application code.
- Native clipboard services transfer UTF-8 text and validated RGBA images. X11 ownership now survives across service calls, and write/read/restore round trips are automated.
- GitHub Actions executes real Win32, AppKit, Wayland, and lightweight Linux windows, input, layout, final platform captures, Viewer scenarios, and memory sampling.
