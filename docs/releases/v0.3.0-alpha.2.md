# ZSUI v0.3.0-alpha.2

## 概览

此预发布版本包含桌面运行时、文字缓存、布局与交互可靠性改进，继续使用同一份
Rust 应用代码连接 Win32、AppKit 与 Linux 原生宿主。

## 主要变更

- 文字引擎定期老化 cosmic-text 成形 run，限制持续变化的字符串在长期运行窗口中的缓存积累。
- 修正横向/纵向布局的交叉轴收缩和文字测量，并统一原生光标与绘制使用的文字缩放。
- NavigationView、SplitView 与 DataGrid 通过受控尺寸、稳定 ID、指针捕获和类型化消息处理调整大小。
- 原生效果和窗口命令使用有界准入与队列预算，保留已接受的任务并遵守窗口生命周期。
- 文件与目录选择区分成功、明确取消及提供方错误；AppKit 文件面板使用原生模态和主线程调度。
- 统一语义图标及平台绘制，并改进 Windows ClearType 子像素顺序和字体 hinting 策略。
- 中文与英文 README 使用统一结构，提供可运行的入门示例、feature 分组、构建依赖、平台边界和文档导航。

## 使用与迁移

```toml
[dependencies]
zsui = "0.3.0-alpha.2"
```

应用从 `zsui::prelude` 或 `zsui::stable` 使用界面门面。旧的 Workbench 组合已移除，
使用基础布局和明确需要的导航、文档或分栏组件组合界面。
`0.3.0-alpha.2` 仍是预发布版本；兼容性范围见 [API 稳定性](../api-stability.md)。

## 平台范围

Win32、AppKit、Linux Direct 与可选 GTK4 宿主已有目标平台运行验证。
输入法候选窗和屏幕阅读器的完整体验仍需目标环境人工检查。
macOS 等复杂度性能矩阵的隐藏应用步骤尚未通过，不能据此给出完整 macOS 性能结论。
触摸/惯性滚动、复杂富文本和 Android 运行时继续按独立能力推进。

## Overview

This prerelease improves desktop runtime reliability, text-cache retention, layout and
interaction while preserving one Rust application model across Win32, AppKit and Linux.

## Changes

- Periodically age cosmic-text shaped runs to bound retention of changing strings in long-lived windows.
- Fix cross-axis layout collapse and text measurement, and share normalized text scale between native caret geometry and painting.
- Resize NavigationView, SplitView and DataGrid through controlled extents, stable IDs, pointer capture and typed messages.
- Use bounded admission and queue budgets for native effects and window commands, retaining accepted work through event-loop budgets and window lifecycle changes.
- Distinguish successful file/directory selection, explicit cancellation and provider errors; use native modal sessions and main-thread scheduling for AppKit panels.
- Align semantic icons and platform rendering, including Windows ClearType stripe order and font hinting policy.
- Organize both READMEs around runnable setup, grouped features, native build dependencies, platform scope and focused documentation.

## Migration and scope

Use `zsui::prelude` or `zsui::stable` for application authoring. The legacy Workbench
composition has been removed; compose basic layouts with the navigation, document or
split-view components the application needs. This remains a prerelease; see the
[API compatibility policy](../api-stability.md).

Win32, AppKit, Linux Direct and the optional GTK4 host have target runtime evidence.
Candidate-window and screen-reader experience still requires manual target checks.
The application-hiding step in the macOS equal-complexity performance matrix remains
unresolved, so that matrix does not establish complete macOS performance results.
Touch/inertial scrolling, complex rich text and the Android runtime remain separate work.
